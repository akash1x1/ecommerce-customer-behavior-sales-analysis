# E-Commerce Customer Behavior & Sales Analysis

An exploratory data analysis (EDA) project using Python to analyze e-commerce transactions, customer behavior, product sales, payment methods, device usage, and sales trends.

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an e-commerce transaction dataset containing information about customers, orders, products, transactions, payments, devices, ratings, and dates.

The main goal is to understand:

- Customer purchasing behavior
- Product category performance
- Sales and transaction patterns
- Payment method and device usage
- Monthly sales trends
- Transaction amount distribution
- Outliers and skewness
- Relationships between numerical variables

The analysis is performed using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.
